# codex-ja Implementation Plan

**Goal:** Implement the design in `codex-ja-design-v1.0.md` as an independent, tested
Textual TUI + diagnostic CLI that reads Codex rollout JSONL read-only, protects Markdown,
and translates through a loopback-only OpenAI-compatible PLaMo server.

**Spec:** `codex-ja-design-v1.0.md` (binding authority).

## Global constraints (verbatim values from the spec)

- Python >= 3.12, uv + committed `uv.lock`, console script `codex-ja`.
- Poll 250 ms, session list refresh 2 s, connect timeout 3 s, read timeout 60 s,
  total 90 s, 1000 code points per segment, 1 HTTP worker, initial 50 messages,
  history page 50, pending queue 32, max line 8 MiB, poll read 1 MiB.
- Translation URL: HTTP, IP literal only, loopback or RFC1918, path `/v1`,
  no userinfo/query/fragment, `trust_env=False`, no redirects, no retries.
- Never write under `CODEX_HOME`. Never send user/tool/reasoning/system bodies.
- No cloud fallback, no plugins/ORM/repository abstractions, no new settings.

## Phase / task breakdown

1. **models.py + config.py** — dataclasses/enums, TOML + env resolution, URL validation.
   Tests: default/explicit config, unknown keys, missing model, URL accept/reject table.
2. **events.py** — allowlist extractor for L/P, Plan, phase mapping, unknown mode.
   Tests: A01–A03, A06–A08 extraction-level.
3. **session.py** — discovery, meta read, child filtering, `SessionReader` with bounded
   incremental reads. Tests: A04, A05, A18, discovery/sort/dup.
4. **markdown.py** — line-oriented units, block classification, inline protection,
   marker validation/restore, long splitting, skip rules. Tests: A14–A16, A23.
5. **cache.py** — SQLite cache, key composition, perms, non-destructive failure.
   Tests: A19–A21.
6. **translation.py** — httpx client + single-worker scheduler, pause/retry, dedupe.
   Tests: A10–A13, A22.
7. **cli.py** — `doctor`, `sessions`, `inspect`, TUI launch, exit codes.
   Tests: A26.
8. **ui.py** — store/monitor + Textual app, original-first rendering, keys, scroll.
   Tests: A17, A25 (Pilot) + headless monitor tests.
9. **README + full verification** — real Codex/PLaMo checks, ruff, pytest, delay report.

## Decisions (rulings)

- No controller module exists in the spec's tree; orchestration lives in `ui.py`.
- Translation units are single physical prose lines inside translatable blocks. This
  preserves newlines/markers by construction; multi-line or nested blocks stay original
  (§7.1 "曖昧なブロックは原文保持").
- Unknown-mode sessions are displayed as unsupported and no body is sent.

## Verification

`uv sync --locked`, `uv run pytest -q`, `uv run ruff check .`,
`uv run ruff format --check .`, plus real `doctor` / `inspect` / TUI manual run.
